# Testes

Antes de gerar código do jogo, execute os testes públicos/sintéticos do Nakagawa e registre versões, comando, saída e testes ignorados. Uma validação de manifesto ou compilação não comprova comportamento do jogo. Após disponibilizar runtime, testar abertura, menus, seleção, corrida completa, itens, retorno, save e reabertura; comparar GE, áudio e sincronização com uma referência PSP. Confirmar em Switch físico com o usuário. Não declarar sucesso com áudio desativado.
